# Antigravity IDE & MCP Orchestrator Design Brief ## Vision Antigravity is a "Zero-G" generative IDE that moves beyond the static file-tree paradigm into a spatial, intent-driven canvas. MCP (Model Context Protocol) serves as the "sensory system," connecting the AI agent to external data (GitHub, Slack, Logs, DBs). ## Core Screens to Design 1. **The Zero-G Canvas**: The main workspace where code is manipulated as spatial logic, not just text files. 2. **MCP Orchestrator**: A "Docker-like" dashboard for managing active MCP servers, monitoring token usage, and defining sensitive data boundaries. 3. **Intent-Driven Navigator**: A high-level command center where developers orchestrate AI agents and "context weight" for servers. 4. **Context Debugging Lab**: A tool for inspection of exactly what context an AI is receiving through the MCP bridge. ## Visual Style - **Theme**: Dark, high-contrast "Void" aesthetic (deep blacks, neon accents). - **Metaphor**: Spatial mapping, 3D links, floating nodes. - **Brand**: "Antigravity" — weightless, fluid, high-tech. ## Key Features - **Hot-swappable MCP Servers**: Drag-and-drop integration for K8s diagnostics, DB schema parsers, etc. - **Sensitive Boundaries**: Visual obfuscation zones for proprietary data. - **Context Weighting**: Sliders to prioritize Slack discussions vs. Git history.
